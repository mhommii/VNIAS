# Bioinformatics & Molecular Docking — VNIAS

Learning materials from the VitaNova International Alliance for Sciences online internship.

## Overview

This repository documents my developing bioinformatics skills through guided internship exercises. The current upload is a reference protein structure; analysis outputs will be added as the exercises are documented.

## Current material

| File | Description |
| --- | --- |
| [1HHP.pdb](1HHP.pdb) | Deposited structure of unliganded HIV-1 protease, used as a learning resource. |

The file header identifies X-ray diffraction at **2.70 Å resolution**. These are metadata from the deposited structure, not measurements or results generated by me.

## Learning focus

The internship covers sequence analysis, protein structure validation and refinement, and preparation for molecular docking. My session updates describe introductory work with BLAST, Discovery Studio, PROCHECK, ERRAT, and multiple sequence alignment.

## Documentation status

Validation reports, alignment files, refinement outputs, and docking results are not yet included. No original structural determination or completed docking study is claimed.

For each documented exercise, include the input accession and sequence or structure, software/version, parameters, saved output, and a short interpretation with limitations.
